# 🪞 AuraMirror | Landing Page Oficial

> Sitio web interactivo y catálogo digital para **AuraMirror** (Glow Mirror), un prototipo de espejo multifuncional con ventilación integrada, iluminación LED y power bank interna alojado en una estructura de madera artesanal. Desarrollado para la Feria Empresarial de la **Institución Educativa CASD**.

---

## ✨ Características

* **Galería Interactiva:** Carrusel automático con temporizador, controles manuales e indicadores de diapositiva.
* **Visor Lightbox:** Inspección de fotos en pantalla completa con un solo clic.
* **Animaciones al Scroll:** Efectos de revelado dinámico (`IntersectionObserver`) optimizados para rendimiento sin librerías pesadas.
* **Diseño Responsivo:** Layout adaptativo usando CSS Grid y Flexbox para móviles y escritorio.
* **Sección de Estandarte:** Descarga directa del sticker oficial promocional e información del stand.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica accesible.
* **CSS3:** Variables CSS (`:root`), sombras ambientales y gradientes pastel sin frameworks externos.
* **JavaScript (Vanilla):** Lógica del carrusel, lightbox y animaciones de scroll.
* **Google Fonts:** Tipografía *Plus Jakarta Sans*.
